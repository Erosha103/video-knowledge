# Система управления знаниями для производства видеороликов и моушн-графики

Учебная база знаний для видеомонтажёров и моушн-дизайнеров. В ней хранятся карточки с приёмами работы и проверками для подготовки, монтажа, анимации и экспорта. Каждая карточка находится в отдельном JSON-файле. Программа автоматически читает из файла четыре характеристики карточки: название, категорию, теги и описание.

## Возможности

- Просмотреть список карточек с названием, категорией и тегами.
- Найти карточки по названию, категории, тегам или описанию. Каждый фрагмент запроса должен встречаться в тексте карточки хотя бы как часть слова. Регистр букв значения не имеет.
- Открыть карточку целиком по идентификатору, указанному в первом столбце списка.
- Пополнить базу новым JSON-файлом. Карточка появится при следующем запуске.

## Запуск

Нужен Python 3.9 или новее. Перейдите в папку проекта и запустите:

```bash
python3 knowledge.py list
python3 knowledge.py search "анимация ключевые"
python3 knowledge.py show easing
```

Вторая команда найдёт карточку «Ускорение и замедление в анимации», третья покажет её описание. Для другой папки с карточками укажите `--cards ПУТЬ` перед командой.

## Как добавить карточку

Создайте в папке `cards` файл с уникальным именем, например `cut-on-action.json`. Имя без расширения станет идентификатором карточки. Заполните четыре поля:

```json
{
  "title": "Склейка на движении",
  "category": "Монтаж",
  "tags": ["склейка", "движение"],
  "description": "Сопоставьте фазу движения в двух планах, затем проверьте переход на обычной скорости."
}
```

Если файл повреждён или в нём отсутствует обязательное поле, команда `list` или `search` сообщит его имя и продолжит работу с остальными карточками. Код завершения в этом случае будет ненулевым.
