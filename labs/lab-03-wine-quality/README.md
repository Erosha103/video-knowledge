# Лабораторная работа 3 — Wine Quality по CRISP-DM

**Задание:** решить задачу с винами из указанного набора Kaggle по подходу CRISP-DM и предоставить общедоступную ссылку на Jupyter notebook.

[Открыть выполненный ноутбук](wine_quality_crisp_dm.ipynb) · [Открыть в Colab](https://colab.research.google.com/github/Erosha103/video-knowledge/blob/main/labs/lab-03-wine-quality/wine_quality_crisp_dm.ipynb)

Я рассматриваю задачу как классификацию исходной дегустационной оценки `quality` от 3 до 9 по 11 химическим измерениям и типу вина. Ячейки уже выполнены: таблицы, графики, прогнозы и выводы можно посмотреть без запуска.

## Этапы CRISP-DM

1. **Business Understanding.** Сформулированы прикладной сценарий, ML-задача, метрики и заранее выбранный ориентир сравнения с базовым решением.
2. **Data Understanding.** Проверены состав файла, распределения, пропуски и повторы. Графики зависимостей построены на обучающей части.
3. **Data Preparation.** Удалены полные дубликаты. Одинаковые входные измерения объединены в группы для разделения данных. Заполнение пропусков, кодирование типа вина и стандартизация выполняются внутри Pipeline.
4. **Modeling.** На одинаковых фолдах сравнены DummyClassifier, LogisticRegression и RandomForestClassifier. Гиперпараметры выбираются на трёхкратной групповой кросс-валидации.
5. **Evaluation.** Выбранная модель оценена на отложенных 1 066 наблюдениях. Приведены метрики, матрица ошибок, результаты по классам и типам вина, разбор ошибок и важность признаков.
6. **Deployment.** Обученный Pipeline сохраняется и загружается обратно, выполнен пример прогноза. Описаны ограничения, проверка на новых партиях и следующий цикл улучшения.

## Полученный результат

Ориентир прироста macro-F1 на 0,10 выбран мной для учебного сравнения; в задании нет заданного порога точности.

По кросс-валидации выбран случайный лес: 250 деревьев, `min_samples_leaf=3`, `class_weight=balanced_subsample`.

| Метрика на отложенном тесте | RandomForest | DummyClassifier |
| --- | ---: | ---: |
| Macro-F1 | 0,298 | 0,083 |
| Balanced accuracy | 0,286 | 0,143 |
| Accuracy | 54,7% | 41,3% |
| MAE, балла | 0,496 | 0,674 |
| Ошибка не больше одного балла | 96,2% | 92,0% |

Модель превосходит базовое решение, но качество распознавания редких оценок остаётся слабым: полнота классов 3 и 9 на этом тесте равна нулю. Доля ошибок не больше одного балла не является точностью классификации. Полученного результата недостаточно для внедрения без независимой проверки на новых партиях вина.

## Повторный запуск

Проверено на Python 3.12.14. Скачайте папку лабораторной с `data/` и `requirements.txt`. Для отдельного окружения:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt notebook
python -m notebook wine_quality_crisp_dm.ipynb
```

В Jupyter выберите ядро этого окружения и выполните **Restart Kernel → Run All**. В ноутбуке зафиксированы случайные состояния и версии библиотек. Для повторения исходных чисел используйте версии из `requirements.txt`; время выполнения зависит от компьютера.

Папка `results/` содержит небольшие таблицы и сводку выполненного эксперимента. При запуске в `artifacts/` создаются обученная модель, прогнозы и таблицы. Файл модели не требуется для просмотра работы и создаётся заново при выполнении ноутбука.
