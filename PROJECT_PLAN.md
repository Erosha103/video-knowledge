# Проект системы управления знаниями для производства видеороликов и моушн-графики

## Описание проекта

При подготовке роликов монтажёр и моушн-дизайнер регулярно возвращаются к одним и тем же приёмам и проверкам. Если записи разбросаны по заметкам, нужную инструкцию приходится искать заново. Система хранит такие знания в карточках и позволяет быстро найти нужную по теме или ключевым словам.

**Цель проекта.** Сделать локальную базу знаний, которую можно пополнять и использовать при подготовке, монтаже, анимации и экспорте роликов.

**Объект.** Карточка знаний. Источник данных — JSON-файлы в папке `cards`. Программа автоматически извлекает четыре характеристики: название, категорию, теги и описание. Пользователь может просмотреть список, найти карточку по словам и прочитать инструкцию целиком.

**Результат.** Работающая консольная программа, четыре демонстрационные карточки, этот проектный план и README с инструкцией запуска и пополнения базы.

## Этапы работ

| Этап | Работы | Срок | Результат |
| --- | --- | --- | --- |
| 1. Определить задачу | Описать пользователей базы и вопросы, с которыми они будут к ней обращаться. | 1 день | Описание проекта и критерии готовности. |
| 2. Подготовить данные | Выбрать обязательные поля карточки и составить примеры по четырём этапам производства. | 1 день | Формат карточки и начальный набор знаний. |
| 3. Разработать программу | Реализовать чтение карточек, проверку полей, список, поиск и просмотр. | 2 дня | Работающая программа. |
| 4. Проверить работу | Запустить программу с демонстрационными и новыми карточками, проверить пустую базу и ошибки чтения. | 1 день | Проверенные сценарии и исправленные ошибки. |
| 5. Подготовить сдачу | Описать возможности и запуск в README и разместить проект на GitHub. | 1 день | Репозиторий с кодом, карточками и документацией. |

Общая оценка — 6 рабочих дней для одного исполнителя.

## Ресурсы

- Python 3.9 или новее и терминал.
- Текстовый редактор и демонстрационные JSON-карточки.
- Репозиторий GitHub для сдачи проекта.

## Критерии готовности

1. Программа запускается и извлекает название, категорию, теги и описание из файлов карточек.
2. Новая корректная карточка появляется в результатах после следующего запуска. Карточка с ошибкой диагностируется, доступные корректные карточки продолжают выводиться.
3. README в репозитории GitHub кратко описывает назначение, возможности, запуск и пополнение базы.
